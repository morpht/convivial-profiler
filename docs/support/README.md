# Support

Find a collection problem or maintain the guide alongside the library:

- [Troubleshooting](troubleshooting.md) — inspect each stage of a pipeline and resolve common configuration problems.
- [Maintaining and publishing](maintaining.md) — edit the documentation source, validate links and examples, and publish through GitBook Git Sync.
