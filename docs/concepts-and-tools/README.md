# Concepts and tools

The ideas used throughout the configuration, plugin reference, and usage chapters:

- [Profilers and profiles](profilers-and-profiles.md) — sources, processors, destinations, and the visitor information they produce.
- [Data pipelines](data-pipelines.md) — collection order, asynchronous HTTP responses, and repeated collection.
- [Storage and expiry](storage-and-expiry.md) — internal namespaces, published values, site identity, and retention.
- [Consent and data handling](consent-and-data.md) — when collection runs, where data goes, and what the cookie-consent argument controls.

Use these chapters to trace a value from its source through processing to the output your site reads.
