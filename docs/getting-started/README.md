# Getting started

Run a small example before configuring personalisation for your site. You will collect a topic from the URL and inspect the value published in browser storage:

- [Installation and first collection](installation.md) — install the dependencies, run the local example, and load the library on your site.

You need Node.js 20.9.0 or later and npm 10.1.0 or later for local development. Once the example works, read [Concepts and tools](../concepts-and-tools/README.md) to understand how its stages fit together.
