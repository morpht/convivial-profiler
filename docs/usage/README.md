# Usage

Apply the library's concepts and configuration to a working integration:

- [Combining audience signals](audience.md) — prefer an explicit audience choice over inferred page interests and provide a default.
- [Drupal integration](drupal.md) — supply the settings and assets, initialise collection, and avoid repeated execution after AJAX requests.

Each chapter explains what the configuration does and how to verify its result. Start with [Installation and first collection](../getting-started/installation.md) if you have not run the library locally.
