# Configuration

Configure the library by defining the pipelines it should run and the options for each plugin:

- [Profiler configuration](profilers.md) — the configuration object, required arrays, destination locations, pipeline ordering, and deferred HTTP collection.

Use the [Plugin reference](../reference/README.md) for individual plugin options. The [Combining audience signals](../usage/audience.md) example shows how several configured pipelines contribute to one published result.
